Set up Training Export

Downloads your own Garmin sessions and health data into a folder on this computer, through Garmin's official Personal API.

Make a Personal API key

On Garmin Connect (web): Personal API Key → Create. One year is the longest. Garmin shows the key once, so copy it.

Paste the key

Kept in Windows' own password store on this computer, and sent only to Garmin.
