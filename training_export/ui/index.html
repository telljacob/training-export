Set up Training Export

Downloads your own Garmin activities and health data into a folder on this computer, through Garmin's official Personal API.
On Garmin Connect (web), make a Personal API key: Personal API Key → Create. One year is the longest. Garmin shows the key once, so copy it.
Paste the key here. It's kept in Windows' own password store on this computer and sent only to Garmin.
